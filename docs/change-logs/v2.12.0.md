# v2.12.0 — 2026-05-29

## Features
- **cbm/document**: Thay thế JWT-in-URL bằng short opaque shareId (12 ký tự) để tránh LLM hallucination khi copy link
- **cbm/document**: Lưu share links trong mảng `shareLinks[]` trên document — persistent, audit trail đầy đủ
- **cbm/document**: Thêm endpoint revoke share link (`DELETE /documents/:id/share/:shareId`)
- **cbm/document**: Thêm endpoint list share links kèm status active/expired/revoked (`GET /documents/:id/shares`)
- **cbm/document**: Sparse index trên `shareLinks.id` cho public lookup hiệu quả
- **cbm/document**: Lazy prune entries expired/revoked cũ khi tạo link mới
