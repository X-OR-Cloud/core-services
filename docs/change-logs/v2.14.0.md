# v2.14.0 — 2026-05-31

## Features

- **aiwm/conv-switch**: Thêm tính năng quản lý conversation cho user
  - `/conv` slash command (connection channels): list 10 conv gần nhất, `/conv new` tạo conv mới, `/conv <num>` switch conv
  - `conv:list`, `conv:new`, `conv:switch` WS events (Chat SDK / CWS gateway)
  - Redis pin `cnv:pin:{orgId}:{agentId}:{userId}` — override cá nhân lên trên conversation mode
  - `resolveConversation` check Redis pin trước, fallback về mode logic nếu không có pin hoặc pin stale
  - Numbering theo vị trí canonical sort `{createdAt:1, _id:1}` — không thêm field DB
  - Query scope theo mode: `shared` = `(orgId, agentId)`, `per-user`/`per-session` = `(orgId, agentId, userId)`
