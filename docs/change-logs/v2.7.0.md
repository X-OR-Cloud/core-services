# v2.7.0 — 2026-05-26

## Features
- **aiwm/agent**: thêm `visibility` field (private/org/restricted) cho Agent — kiểm soát agent nào có thể thấy/truy cập agent
- **aiwm/tool**: `toolDefinitions` trong `/agents/connect` response — flatten `functions[]` từ tất cả api tools thành definition sẵn sàng để agent client auto-init
- **aiwm/tool**: `functions[]` model cho api-type tools (1 tool = N HTTP endpoints) — thêm `ApiToolFunctionDto`, `ApiToolExecutionDto`, cập nhật schema + DTO
- **aiwm/tool**: phân quyền create/update/delete tool — `organization.owner` và `organization.editor` được phép quản lý tool `api`, `mcp`, `custom`; `builtin` không thể tạo/sửa/xóa
- **aiwm/mcp**: backward compat fix cho `mcp.service.ts` — dùng `functions[0]` thay vì `execution.method/path` (đã bị xóa khỏi type)
