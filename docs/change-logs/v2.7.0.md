# v2.7.0 — 2026-05-22

## Features
- **cbm/order**: Thêm booking fields top-level (`checkIn`, `checkOut`, `invoiceId`) + `metadata` support cho `bookingType`/`guestType`
- **cbm/order**: Mở rộng status enum: thêm `deposited`, `checked_in` (giữ nguyên existing statuses)
- **cbm/order**: Thêm booking state machine endpoints: `POST /orders/:id/confirm|deposit|checkin|checkout`
- **cbm/order**: Thêm `GET /orders/availability` — kiểm tra phòng trống theo productIds + date range (hard block `room` và `maintenance`)
- **cbm/order**: Thêm `GET /orders/calendar?month=YYYY-MM` — lịch booking theo tháng
- **cbm/order**: Auto availability check khi tạo booking (`bookingType: room`), throw 409 nếu conflict
- **cbm/invoice**: Thêm `orderId` field để link Invoice ↔ Order
- **cbm/invoice**: Thêm `POST /invoices/:id/share-link` — generate public link 72h TTL
- **cbm/invoice**: Thêm `GET /invoices/public/:token` — xem invoice không cần login, ẩn `customer.phone`
- **cbm/product**: Thêm `imageIds` field; `metadata` đã có qua BaseSchema
- **cbm/scripts**: Setup script `setup-hoa-lu-resort.ts` — tạo 41 phòng + 4 categories + dịch vụ phụ cho Hoa Lư Garden Resort
