# v2.8.0 — 2026-05-27

## Features

- **aiwm/vws**: Thêm mode `vws` — Voice WebSocket Gateway (port 3410) relay audio 2 chiều giữa mobile app và Google Gemini Live API
- **aiwm/model**: Thêm field `protocol` (`rest` | `ws`) để phân biệt voice model dùng HTTP hay realtime WebSocket
- **aiwm/deployment**: `buildEndpointInfo()` trả về VWS endpoint URL cho deployment có model `type=voice, protocol=ws`
- **ecosystem**: Thêm PM2 process `core.aiwm.vws00` (port 3410)
- **docs**: Proposal thiết kế Mobile Voice Assistant (`docs/aiwm/MOBILE-VOICE-ASSISTANT-PROPOSAL.md`)
