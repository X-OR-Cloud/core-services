# v1.17.1 — 2026-05-08

## Fixes
- **aiwm/node-gateway**: bỏ hardcoded fallback `'hydra-secret-key'` cho `JWT_SECRET` ở `_authMiddleware`. Nếu env không có JWT_SECRET, throw error ngay thay vì verify token với secret giả (security risk: ai biết secret giả có thể ký token vượt qua auth).

## Reverts
- **aiwm/redis-io-adapter**: revert defensive ConfigService lookup từ v1.16.2. Verify trên prod (logs `[REDIS-ADAPTER] ✅ Redis adapter connected successfully` với URL đúng `redis://***@10.10.0.100:6379`) thấy `process.env.REDIS_URL` đọc qua `ConfigModule.forRoot()` runtime mutation đã work bình thường — fix trước đó là defensive thừa. Revert giữ code minimal.
