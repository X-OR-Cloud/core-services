# v1.13.0 — 2026-05-01

## Features

- **cbm/payment**: Thêm `webhookUrl` + `webhookSecret` vào Payment schema — caller tự cung cấp URL callback thay vì cấu hình env
- **cbm/payment**: Outbound webhook dùng BullMQ (retry exponential backoff: 30s → 60s → 120s, 4 attempts) thay vì direct fetch
- **cbm/payment**: Áp dụng `ServiceAccountPermissionGuard` + `@RequirePermission` cho `create`, `findAll`, `findOne` — cho phép Service Account (PAG) gọi CBM với permissions granular
- **cbm/app**: Tích hợp `BullModule.forRootAsync` với Redis cho toàn CBM service
