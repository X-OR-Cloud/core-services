# v1.5.1 — 2026-04-28

> Baseline release — đánh dấu bắt đầu áp dụng semantic versioning (trước đó là 0.5.1).

## Features

- **aiwm/aws**: tách Agent WebSocket Gateway thành process riêng (MODE=aws, port 3400–3402) — chỉ phục vụ engineer agents
- **aiwm/nws**: tách Node WebSocket Gateway thành process riêng (MODE=nws, port 3403–3406)
- **aiwm/cws**: tách Chat WebSocket Gateway thành process riêng (MODE=cws, port 3407–3409) — phục vụ user/anonymous/assistant
- **aiwm**: inject memory snapshot vào system prompt cho memory-enabled agents
- **aiwm**: propagate `instruction-updated` reload tới engineer agents qua AWS
- **aiwm**: agent JWT tự động refresh trước khi hết hạn để tránh 401 trên heartbeat
- **aiwm**: engineer agent token lifetime cấu hình qua env (`ENGINEER_TOKEN_TTL`)
- **aiwm/aws**: thêm `message:typing` handler cho engineer agents
- **aiwm/con**: multi-instance connection worker — per-connection distributed lock + Redis dedup
- **aiwm/agt**: V2 multi-runner scaling — per-conversation queues và locks
- **base**: thêm build-time HMAC license guard với `@SkipLicenseCheck` decorator
- **mona**: thêm `agg` mode cho metrics aggregation worker (MODE=agg, BullMQ, no HTTP)
- **infra**: hoàn thiện Dockerfiles cho tất cả services + air-gap build fixes

## Fixes

- **aiwm**: cast `content-type` header sang string để fix TypeScript error khi prod build
- **aiwm**: correct WS bootstrap port fallbacks trong ecosystem config
- **aiwm/nws**: thêm `/ws/node` namespace alias cho backward-compat với xnode clients cũ
- **aiwm/cws**: đăng ký message handlers trên `/ws/chat` alias namespace
- **aiwm**: `mcpServers` và `allowedFunctions` được cập nhật khi token reload
- **aiwm**: loại bỏ legacy ChatGateway khỏi API mode
- **aiwm/aws+cws**: loại bỏ triple Discord reply từ engineer agent responses
- **aiwm/presence**: thay thế stale agent socket IDs khi reconnect
- **aiwm/aws**: dedup `message:send` từ stale agent sockets
- **aiwm/con**: dừng runner khi mất distributed lock
- **aiwm/agt**: `allowedFunctions` rỗng disable tất cả tools (thay vì allow all)
- **cbm**: đảm bảo Qdrant collection tồn tại trước khi MongoDB create và search
- **cws**: scope `presence:update` events vào conversation room thay vì tất cả sockets
- **dgt**: thêm `LlmProviderModule` vào `SentimentSignalModule` và `AppIngestionModule`
- **dgt**: chuyển `NewsapiCollector` sang dùng `LlmRouterService`
- **base/mongoose**: thêm tên collection tường minh vào tất cả Mongoose schemas để tránh obfuscation khi build production
