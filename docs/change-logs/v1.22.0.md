# v1.22.0 — 2026-05-09

Merge `feature/adaptive-rag` vào main. Branch này phân nhánh từ `v1.14.0` và phát triển song song với main qua các version `v1.15-v1.21`. Nội dung dưới đây tổng hợp các features adaptive-rag từ branch (đã từng đánh số v1.15.0 và v1.16.0 trên branch — không liên quan đến v1.15.0/v1.16.0 đã release trên main).

## Features

- **aiwm/agent**: Thêm field `ragConfig` (`AgentRagConfig`) vào Agent schema — cấu hình Adaptive RAG pipeline v2, backward-compatible với `ragEnabled`/`ragCollectionIds`/`ragSettings` cũ.
- **aiwm/agent-worker**: Tạo `AdaptiveRagService` với pipeline đầy đủ: intent classification → collection routing → parallel search → relevance grading → query reformulation → hallucination check.
- **aiwm/agent-runner**: Tích hợp Adaptive RAG v2 vào `augmentWithRagContext` — tự động dùng v2 khi `ragConfig` present, fallback về v1 khi không có.
- **aiwm/agent**: Thêm DTOs `AgentRagConfigDto`, `RagIntentRuleDto`, `RagCollectionConfigDto`, `RagGraderConfigDto` vào `CreateAgentDto`/`UpdateAgentDto`. Expose `ragConfig` trong `AgentConnectResponseDto` cho engineer agents.
- **aiwm/adaptive-rag**: history-aware intent classification trong `AdaptiveRagService`.
- **aiwm/adaptive-rag**: thêm `ragConfig.traceLevel` (`off` | `summary` | `verbose`, mặc định `summary`) để điều khiển độ chi tiết log pipeline RAG vào conversation actions.
  - `off`: không publish action nào cho RAG (chỉ `sources` đính trong message cuối).
  - `summary` (mặc định): 1 cặp `tool_use`/`tool_result` quanh search step, có metadata đầy đủ (intent, query, collections, chunksPerCollection, topScores, timing).
  - `verbose`: bổ sung `thinking` action cho intent classification, query reformulation (khi xảy ra), và relevance grading (khi enabled), kèm timing từng bước.
- **aiwm/adaptive-rag**: nâng cấp content `tool_use`/`tool_result` của RAG search — thêm `toolName="AdaptiveRagSearch"`, `toolInput`/`toolResult` JSON với intent, collections, chunks per collection, top scores, latency để hỗ trợ debug và replay decision tree.

## Notes

- `ragConfig.intentClassifier.enabled = false` → bỏ qua LLM classification, dùng heuristic + default `SIMPLE_RAG`.
- `ragConfig.grader.relevanceEnabled = false` → bỏ qua relevance grading, giữ tất cả chunks.
- Legacy `ragEnabled`/`ragCollectionIds`/`ragSettings` vẫn hoạt động bình thường.
- Backward compatible: `traceLevel` optional, default `summary` giữ hành vi tương đương phiên bản trước (chỉ khác content tool_use/tool_result giàu metadata hơn).
- Tradeoff: verbose mode tăng ~3-5 actions mỗi turn có RAG, tăng latency ~5-10ms (publish + DB save async, không block pipeline).
