# v1.16.2 — 2026-05-08

## Fixes
- **aiwm/redis-io-adapter**: Socket.IO Redis adapter fail connect (ECONNREFUSED 127.0.0.1:6379) khi pm2 không inject env vars vào `process.env`. Adapter trước đây đọc `process.env.REDIS_URL` trực tiếp → undefined → fallback `localhost` → adapter rơi vào in-memory mode → cluster instances không sync `socketsJoin` qua Redis pub/sub. Sửa: ưu tiên đọc qua `ConfigService` (load `.env` qua `ConfigModule`) trước khi fallback `process.env`.
- **aiwm/bootstrap-agent-ws**: cùng cách fix cho dòng log Redis URL.

## Notes
- Bug nguyên nhân gốc của vấn đề agent jade không nhận message:new ở v1.16.1. pm2 `env_file: '.env'` trong ecosystem.config.js không populate `process.env` của process running — chỉ ConfigModule mới load .env qua đường internal. Workaround v1.16.1 (per-agent room) vẫn giữ làm fallback robust.
- Áp dụng pattern này cho `bootstrap-chat-ws.ts` và `bootstrap-node-ws.ts` (CWS, NWS) sau nếu phát hiện cùng vấn đề — em chưa sửa vì chưa verify ở 2 service đó.
