# v1.9.0 — 2026-04-28

## Features
- **cbm/contract**: thêm module Contract với state machine (draft/active/expired/terminated/cancelled), auto-gen code CTR-YYYY-NNNN, e-invoice linking
- **cbm/contract-annex**: thêm module ContractAnnex với state machine (draft/active/cancelled), auto-gen code PL01/PL02…, ServiceItem list với UnitCode enum
- **cbm/invoice**: thêm trường `contractId` và `contractAnnexId` để liên kết invoice với contract/annex

## Notes
- ContractAnnex code tự sinh theo từng contract (PL01, PL02...), không phải global
- ServiceItem hỗ trợ đơn vị tính: month/hour/day/year/license/time/item/package/other
