# v1.9.0 — 2026-04-28

## Features

- **cbm/contract**: thêm module Contract với state machine (draft/active/expired/terminated/cancelled), auto-gen code CTR-YYYY-NNNN, e-invoice linking
- **cbm/contract-annex**: thêm module ContractAnnex với state machine (draft/active/cancelled), auto-gen code PL01/PL02…, ServiceItem list với UnitCode enum
- **cbm/invoice**: thêm trường `contractId` và `contractAnnexId` để liên kết invoice với contract/annex
- **vsm**: Khởi tạo VSM (Voice Service Management) service — control plane cho hệ thống telephony Asterisk PBX
- **vsm/nodes**: CRUD Asterisk nodes với AMI credentials (AES-256-GCM encrypted at rest)
- **vsm/accounts**: CRUD SIP/WebRTC accounts, auto-sync sang Asterisk PJSIP, status/state tracking
- **vsm/trunks**: CRUD SIP trunks, auto-sync sang Asterisk PJSIP
- **vsm/phone-numbers**: CRUD DID phone numbers (inbound/outbound/both)
- **vsm/dialplans**: CRUD Asterisk dialplan contexts + extensions, auto-sync
- **vsm/routes**: CRUD inbound/outbound call routing rules với priority
- **vsm/calls**: Call log CRUD, outbound originate, schedule auto-call, S3 presigned recording URL
- **vsm/webhooks**: Internal AMI bridge webhook handler — CDR, PeerStatus, DeviceStateChange, Dial events, sync results
- **vsm/ami-bridge**: AMI TCP client (auto-reconnect), event forwarder → API webhook, BullMQ command consumer
- **vsm**: Staging deployed — Asterisk 20.6.0 installed, AMI bridge connected

## Notes

- ContractAnnex code tự sinh theo từng contract (PL01, PL02...), không phải global
- ServiceItem hỗ trợ đơn vị tính: month/hour/day/year/license/time/item/package/other
