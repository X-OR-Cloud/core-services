# v2.4.0 — 2026-05-09

## Features

- **iam pilot integrate sys-client** (P3): iam là service đầu tiên dùng `@hydrabyte/sys-client` cho cả setting (JWT TTLs từ sys) và audit-log (login/logout/user create).

### Settings từ sys (P3.1–P3.3)

- **2 ConfigKey mới** trong `@hydrabyte/shared`:
  - `IAM_JWT_ACCESS_TTL_SEC = 'iam.jwt.access_ttl_sec'` (number, default 3600s, range 60–86400)
  - `IAM_REFRESH_TOKEN_TTL_SEC = 'iam.refresh_token.ttl_sec'` (number, default 604800s, range 3600–7776000)
- **SysClientModule.forRoot()** wired vào `services/iam/src/app.module.ts` — global module, inject `SysSettingClient` + `SysAuditClient` + `AuditInterceptor` available everywhere.
- **`auth.service.ts`** — helper `getTokenTtls(orgId)`:
  - **Priority 1**: sys-client `getOrDefault<number>(IAM_JWT_ACCESS_TTL_SEC | IAM_REFRESH_TOKEN_TTL_SEC, orgId, fallback)`
  - **Priority 2**: env `JWT_EXPIRES_IN` (parsed via existing `parseExpirationTime`)
  - **Priority 3**: hardcoded (1h JWT, 7d refresh)
  - Áp dụng cho 3 token-issuing sites: `login()`, `refreshToken()`, `handleGoogleCallback()`
- Removed `// @ts-expect-error - jsonwebtoken types` directives ở 3 chỗ (sign() giờ nhận `expiresIn: number` thay vì `string`, types resolve đúng)

### Audit qua decorator (P3.4)

- **`@hydrabyte/sys-client` imports** trong `auth.controller.ts` + `user.controller.ts`:
  - `@UseInterceptors(AuditInterceptor)` ở class level
  - `@Audit({ resource: 'user', action: 'login', captureResourceId: false })` cho `POST /auth/login`
  - `@Audit({ resource: 'user', action: 'logout', captureResourceId: false })` cho `POST /auth/logout`
  - `@Audit({ resource: 'user', action: 'create' })` cho `POST /users`
- Login event sẽ ghi với `actor.orgId='system'` (chưa có req.user lúc trước handler) — vẫn capture được correlationId, durationMs, result, errorMessage.
- Logout/create capture full actor từ JWT.

### env additions

- `services/iam/.env.example` thêm:
  ```
  SYS_API_URL=http://localhost:3007
  SYS_CLIENT_METRICS_ENABLED=false
  ```
- `JWT_EXPIRES_IN` giữ làm fallback khi sys unreachable.
