# v1.10.0 — 2026-04-29

## Features
- **pag/news-digest**: Thêm quick commands quản lý bản tin qua chat — `tin tức`, `cài tin tức`, `tắt tin tức`, `bật tin tức`
- **pag/news-digest**: 2-turn setup wizard cho phép user chọn chủ đề (6 nhóm) + giờ giao (M/E/B) trong 1 luồng chat
- **pag/news-digest**: Inject thông tin news pref vào LLM context để bot biết trạng thái bản tin của user
- **pag/user-news-prefs**: Thêm `upsert()` và `setActive()` vào `UserNewsPrefsService`
- **cbm/provider**: Module mới quản lý cấu hình provider tích hợp bên ngoài (payment-gateway, einvoice). Credentials được mã hoá AES-256-GCM at rest. Endpoints: CRUD, PATCH /config, POST /test, POST /:id/webhook (PayOS/VNPay).
- **cbm/payment**: Hỗ trợ pending gateway payment — `POST /payments { status:'pending', metadata }` tạo PayOS VietQR link, trả về `{ paymentId, qrCode, checkoutUrl, expiredAt }`.
- **cbm/payment**: Webhook handler `handleWebhookPaid()` — auto-create Invoice + Transaction khi PayOS xác nhận thanh toán. Gọi PAG webhook (HMAC-signed) khi thành công.
- **cbm/payment**: Cron job expire pending payments quá `expiredAt` (mỗi phút).
- **cbm/payment**: Reconciliation flow — nếu payment đã `expired` nhưng vẫn được thanh toán: ghi nhận Transaction, flag `reconciliation.needed = true`, gửi Discord alert. Không tự động activate plan.
- **cbm/invoice**: `createAutoInvoice()` — tạo invoice `status: paid` trực tiếp từ gateway payment (không qua state machine).
