# v2.16.0 — 2026-06-04

## Features

- **cbm/domain-config**: Thêm module DomainConfig — quản lý workflow config theo domain và resource
- **cbm/domain-config**: Seed 3 system presets khi bootstrap: `default`, `booking`, `sale`
- **cbm/domain-config**: API endpoint `GET /domain-configs/active` trả về effective config cho org hiện tại
- **cbm/orders**: 5 generic action endpoints: `start`, `confirm`, `activate`, `complete`, `cancel` — driven by DomainConfig
- **cbm/orders**: Rename status `checked_in` → `active` (tổng quát hóa cho mọi domain)
- **cbm/orders**: `POST /orders/:id/process` giữ lại làm deprecated alias → `start`
- **cbm/orders**: Xóa hardcode state machine, chuyển sang config-driven qua `DomainConfigService`

## Notes

- Backward compatible 100% với BepCoba: `/process`, `/complete`, `/cancel` hoạt động như cũ
- Các endpoint `/checkin`, `/checkout`, `/deposit` (chưa có app nào dùng) đã xóa — thay bằng `/activate`, `/confirm`
- Phase 2: Inventory module (auto-sync khi Order transition)
