# v1.15.0 — 2026-05-07

## Features
- **cbm/product, cbm/contact**: nâng cấp `findAll` search — diacritic-insensitive (Vietnamese), multi-word AND, escape regex special chars. Search "ga" / "gà" / "GA" cho cùng kết quả; "phở gà" match cả "Gà nấu phở".
- **base**: thêm util `normalizeSearchText`, `escapeRegex`, `buildSearchFilter` (export từ `@hydrabyte/base`).
- **cbm**: thêm field `searchText` (denormalized) vào `Product` và `Contact` schema, tự động cập nhật qua hook `pre('save')` + `pre('findOneAndUpdate')`.

## Fixes
- **cbm/product, cbm/contact**: fix bug `findAll` bỏ qua filter `$or` — trước đây search trả về toàn bộ documents thay vì lọc đúng. Nguyên nhân: `$or` đặt ở top-level options nhưng `BaseService.findAll` chỉ đọc `options.filter`.

## Notes
- **Migration cần chạy**: `node scripts/backfill-cbm-search-text.js` để populate `searchText` cho dữ liệu cũ (idempotent — an toàn re-run).
- Index mới: `(owner.orgId, searchText)` trên cả `products` và `contacts` collection, được tạo tự động khi service start.
