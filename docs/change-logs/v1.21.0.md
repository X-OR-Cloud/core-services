# v1.21.0 — 2026-05-08

## Features
- **contact**: F-014 — Owner-only access guard for all Contact endpoints. Soft delete now sets `status: inactive` (preserving phone dedup for F-020). `GET /contacts` defaults to `status: active` filter.
- **order**: F-020 — Auto-create/link Contact on order creation. Dedup by `phone + orgId` (regardless of contact status). Silent failure — order creation unaffected if contact logic fails.
- **contact**: Added compound index `{orgId, phone}` for fast F-020 dedup queries.
