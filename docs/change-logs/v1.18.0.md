# v1.18.0 — 2026-05-08

## Features
- **iam/webhook**: Replace BullMQ/Redis event mechanism with App-based webhook — `AppWebhookService` now fires `user.created`, `user.updated`, `user.deleted` events as HTTP POST to `App.webhookUrl` (HMAC-SHA256 signed, fire-and-forget)
- **iam/webhook**: Add `fireForOrg` pattern — automatically finds all active apps in an org with configured webhookUrl and fires to each

## Notes
- Removed `src/queues/` directory and all `IamQueueModule` / `IamEventProducer` dependencies from IAM
- Webhook fires are non-blocking — failures are logged but never surface to the caller
