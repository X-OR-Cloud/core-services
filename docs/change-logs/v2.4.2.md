# v2.4.2 — 2026-05-10

## Fixes

- **iam/app**: `GET /apps?sort=createdAt:desc` trả `400 "sort must be an object"` trên prod. Nguyên nhân: controller dùng trực tiếp `PaginationQueryDto` (validate `sort` là object), trong khi FE gửi string theo convention `parseQueryString` của monorepo.

## Refactor

- **iam/app controller** chuẩn hoá theo CRUD pattern của `template/product`:
  - Move `@UseGuards(JwtAuthGuard, UniverseRoleGuard)` lên class-level
  - Đổi `PaginationQueryDto` → `parseQueryString(query)` + `QueryStringParams` — hỗ trợ filter (`field:gt/gte/lt/lte/ne/in/nin/regex`) + sort (`field:asc/desc`)
  - Bỏ wrap `new Types.ObjectId(id)` thừa và `NotFoundException` thủ công — `BaseService` đã handle
  - Thêm `@RequireUniverseRole()` cho `GET /apps/:id` (trước đây thiếu → JWT user thường vẫn gọi được; nay siết thành `universe.owner` đồng nhất với 4 handler còn lại)

## Docs

- `docs/iam/app/app-api.md` — API reference cho module App: schema, 5 endpoints, cú pháp `parseQueryString`, webhook lifecycle, SSO validation flow.

## Notes

- ⚠️ Behaviour change: `GET /apps/:id` nay yêu cầu role `universe.owner`. FE gọi bằng token non-universe sẽ bị 403.
- Cần build + redeploy `iam` để fix `?sort=createdAt:desc` có hiệu lực trên prod.
