# v2.3.0 — 2026-05-09

## Features

- **sys**: P2 hoàn thành — module `audit-log` + decorator/interceptor + BullMQ ingest worker.

### Sys service (P2.1–P2.6)

- **Audit-log schema** đầy đủ (`service`, `resource`, `resourceId`, `action`, `keyType`, `actor`, `before`/`after`, `requestPayload`, `responseSummary`, `result`, `errorMessage`, `errorCode`, `correlationId`, `occurredAt`, `durationMs`). Indexes: `{ actor.orgId, occurredAt }` (primary), `{ service, resource, action, occurredAt }`, `{ actor.userId, occurredAt }`, `{ correlationId }`, partial `{ keyType, occurredAt }` (chỉ cho secret/setting access).
- **DTOs**: `CreateAuditLogDto`, `CreateAuditLogBatchDto`, `AuditLogQueryDto`, `AuditActorDto` với class-validator.
- **Service**: `findAll` (search/filter/pagination + RBAC), `findById` (org boundary check), `getStats` (aggregate count theo service+action+result trong time window), `persist`/`persistMany` (BullMQ worker call). Server-side defense-in-depth: re-sanitize via lib utility ngay cả khi lib đã sanitize trước.
- **UI controller**: `GET /audit-logs`, `GET /audit-logs/stats`, `GET /audit-logs/:id` — JWT auth, org boundary (universe.owner thấy all, org owner chỉ thấy `actor.orgId == ctx.orgId`).
- **Internal controller**: `POST /audit-logs/internal` — CIDR + APIKey guards, batch ingest. 202 Accepted.
- **BullMQ ingest**: queue name `sys-audit-ingest`, processor `AuditLogProcessor`, persist via `persistMany`. Module `forRoot()` (API mode) vs `forRootWorker()` (BullMQ worker — chỉ mode `wrk`).

### Lib `@hydrabyte/sys-client` audit pieces (P2.7–P2.9, P2.12)

- **`SysAuditClient.log(event)` / `logBatch(events)`** — fire-and-forget BullMQ enqueue. Sanitize + truncate trước khi enqueue (3 lớp theo PROPOSAL §5.2: strip sensitive fields, per-field 1KB / giữ 256 chars, total 4KB cap). Fallback log stdout với marker `AUDIT_FALLBACK` khi BullMQ down. Auto-fill `service` từ options.serviceName, default `actor.orgId='system'` nếu caller không cung cấp.
- **`@Audit({ resource, action, capturePayload?, captureResourceId?, keyType? })` decorator** — gắn metadata vào controller method.
- **`AuditInterceptor`** — capture actor (từ `req.user`, fallback `'system'`), correlationId, requestPayload (sanitized), durationMs, responseSummary `{ id, size }` từ response. Tự động emit success/failure tùy handler outcome.
- **Sanitization util** `sanitizeObject` / `sanitizeWithCap` exported từ lib — share logic giữa client và server.
- **Audit metrics** mới: `sys_audit_enqueue_total{service,action,result}`, `sys_audit_enqueue_failed_total{reason}`. Tổng cộng lib expose **11 Prometheus metrics**.
