# v1.7.0 — 2026-04-28

## Features

- **cbm**: thêm endpoint `POST /knowledge-collections/:id/add-file` — nhận presigned S3 URL, download file, upload S3, queue embedding. Hỗ trợ: `.pdf`, `.docx`, `.xlsx`, `.txt`, `.md`, `.html`
- **aiwm/mcp**: thêm `AddKnowledgeFile` tool (thay thế `UploadKnowledgeFile`) — agent cung cấp presigned URL, CBM xử lý toàn bộ download + upload + indexing. Schema đơn giản: `collectionId`, `fileUrl`, `filename`, `name?`

## Notes

- `UploadKnowledgeFile` (v1.6.0) bị thay thế hoàn toàn bởi `AddKnowledgeFile`. Lý do: tránh LLM phải load binary content qua context, và CBM đã hỗ trợ đầy đủ PDF/DOCX/XLSX.
