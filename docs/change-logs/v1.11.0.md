# v1.11.0 — 2026-04-30

## Features
- **iam/service-accounts**: Module mới — OAuth2 `client_credentials` flow cho inter-service authentication
  - CRUD endpoints: tạo, list, get, update, soft delete
  - `POST /service-accounts/token` — cấp JWT (4h) cho service account
  - Secret được hash bcrypt, rawSecret chỉ trả 1 lần khi tạo
- **libs/base**: Thêm `ServiceAccountPermissionGuard` — kiểm tra granular permissions cho SA token
- **libs/base**: Thêm `@RequirePermission(service, resource, action)` decorator
- **libs/base/JwtStrategy**: Pass-through `permissions` field từ JWT payload
