## Notes

- **Removed services:** `vsm` (Voice Service Management), `pag` (Personal Agent Gateway), `aivp` (AI Video Processing), `vbx` (Video Box), và docs design của `lcm` chưa có code. Các service này tiếp tục sống ở repo biz tách riêng.
- **Repo còn lại:** `template`, `iam`, `noti`, `aiwm`, `cbm`, `mona`, `schd`.
- **Removed from PM2 ecosystem:** 6 process entries (`biz.vsm.api00/01/ami00`, `biz.pag.api00/01/wrk00`). `ecosystem.config.js` còn 33 core processes.
- **Removed env keys:** `PAG_BASE_URL`, `PAG_DISCORD_WEBHOOK_URL`, `GOOGLE_API_KEY` (chỉ PAG dùng) khỏi `.env` và `.env.hbx`.
- **Removed root files:** `CLAUDE_VSM.md`, `CLAUDE_PAG.md`.
- **Removed docs:** `docs/vsm/`, `docs/pag/`, `docs/lcm/`.
- **Removed changelogs:** `v1.8.3.md`, `v1.9.0.md`, `v1.9.1.md`, `v1.10.1.md` (toàn bộ nội dung là biz services). `v1.10.0.md` được edit để chỉ giữ `cbm/*` features.
