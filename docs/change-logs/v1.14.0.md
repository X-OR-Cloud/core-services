# v1.14.0 — 2026-05-05

## Features

- **cbm/product-category**: thêm module quản lý danh mục sản phẩm — CRUD, filter theo status
- **cbm/product**: thêm module quản lý sản phẩm — CRUD, filter theo category/status/search, bulk import/upsert theo code
- **cbm/order**: thêm module quản lý đơn hàng — CRUD, auto-gen code `ORD-YYYYMMDD-NNNN`, state machine (new → processing → done / cancelled), snapshot customer & items
- **cbm/shared-types**: tách `MoneyAmount` interface ra `shared-types/money.types.ts` dùng chung giữa các module

## Fixes

- **cbm/invoice**: đổi tên field `InvoiceItem.unitPrice → price` để đồng nhất với `product.price` và `order.items.price`

## Notes

- `order.customer` là snapshot tại thời điểm tạo đơn — thay đổi Contact sau không ảnh hưởng đơn cũ
- `order.items` lưu snapshot giá — thay đổi giá sản phẩm sau không ảnh hưởng đơn cũ
- FE tự tính `subTotalAmount`, `taxAmount`, `totalAmount` trước khi gửi lên — xem `docs/cbm/order/FRONTEND-API.md`
