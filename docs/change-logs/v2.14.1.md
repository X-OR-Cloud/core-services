# v2.14.1 — 2026-05-31

## Features

- **aiwm/conv-title**: Hỗ trợ đặt tên conversation khi tạo mới hoặc switch
  - Slash command: `/conv new:<tên>`, `/conv <số>:<tên>`
  - WS events: `conv:new { title? }`, `conv:switch { num, title? }`
  - Title lưu persistent vào DB (`conversation.title`), phản ánh ngay trong `conv:list`
