# v1.16.0 — 2026-05-07

## Features
- **cbm/outlet**: Thêm module Outlet — CRUD, activate/deactivate, `GET /outlets/me` trả outlets theo role
- **cbm/outlet-member**: Thêm module OutletMember — assign user vào outlet, auto-set isDefault cho lần đầu assign, unique constraint per (userId + outletId + orgId)
- **cbm/middleware**: OutletContextMiddleware đọc header `x-outlet-id` → `req.outletId`
- **cbm/decorator**: `@CurrentOutlet()` param decorator để lấy outletId trong handler
