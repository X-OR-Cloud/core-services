# v1.16.0 — 2026-05-07

## Features

- **aiwm/adaptive-rag**: thêm `ragConfig.traceLevel` (`off` | `summary` | `verbose`, mặc định `summary`) để điều khiển độ chi tiết log pipeline RAG vào conversation actions.
  - `off`: không publish action nào cho RAG (chỉ `sources` đính trong message cuối)
  - `summary` (mặc định): 1 cặp `tool_use`/`tool_result` quanh search step, có metadata đầy đủ (intent, query, collections, chunksPerCollection, topScores, timing)
  - `verbose`: bổ sung `thinking` action cho intent classification, query reformulation (khi xảy ra), và relevance grading (khi enabled), kèm timing từng bước
- **aiwm/adaptive-rag**: nâng cấp content `tool_use`/`tool_result` của RAG search — thêm `toolName="AdaptiveRagSearch"`, `toolInput`/`toolResult` JSON với intent, collections, chunks per collection, top scores, latency để hỗ trợ debug và replay decision tree.

## Notes

- Backward compatible: `traceLevel` optional, default `summary` giữ hành vi tương đương phiên bản trước (chỉ khác content tool_use/tool_result giàu metadata hơn).
- Tradeoff: verbose mode tăng ~3-5 actions mỗi turn có RAG, tăng latency ~5-10ms (publish + DB save async, không block pipeline). Đổi lại observability đầy đủ để trace classification/grader/reformulate decisions.
